Questions:
1. What does #!/usr/bin/env bash do, and why is it preferable to #!/bin/bash?
  - #!/usr/bin/env bash tells the operating system which interpreter to use to execute the file. #!/bin/bash hardcodes the absolute path to bash. 
 It is preferable to use #!/bin/bash because it is more portable across systems, #!/bin/bash lives locally.   

2. What does chmod +x do, and what happens if you try to run the script without it?
  - It sets the executable permission on the file and allows the operating system to run the file directly as a program.

3. What is the difference between running ./hello_researcher.sh and bash hello_researcher.sh?
  - ./hello_researcher.sh uses the operating system to execute the file directly. bash hello_researcher.sh uses bash and tells it to run the file as a script.
