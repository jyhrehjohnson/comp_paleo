QUESTIONS
1. What is the difference between an SSH public key and a private key? Which one did you add to GitHub and why?
  - A public key is shareable and can live on servers and connect to GitHub. A private key is a hidden key that is never uploaded or shared. It lives on your local server and is identifier when you connect to GitHub.

2. Why must ~/.ssh/id_ed25519 have permissions 600 and not 644?
  - This is our private key, so it needs permissions 600, as it means only I can access it, not a group of users.

QUESTIONS
9. Why should large data files be kept out of Git repositories? What should go in the repository instead?
  - Large data files can slow down git commands, as the repo tries to save each revision of a data file 

10. What is the difference between .gitignore ignoring a file and git rm --cached removing a file from tracking?
  - .gitignore holds files that are being untracked, while git rm --cached still forces git not to track the file, but it is saved on your own hard drive
